# Priyanka Gangavane – React Portfolio

A modern, responsive portfolio website built with React to showcase my education, projects, and skills.  
The design uses a dark neon theme with glowing cards, animated backgrounds, and smooth hover effects inspired by modern developer portfolios.

---

## ✨ Features

- Hero, Education, and Projects sections on a single-page layout
 Screenshot / Preview: ![Portfolio Preview](./hero.jpg)
- Neon-style cards with glowing icons for education details
- Project timeline with alternating left/right blocks
- Pure CSS background effects (stars, gradients, snowfall)
- Responsive design for mobile, tablet, and desktop
- Reusable React components (`Education`, `Project`, `ProjectCard`, etc.)
- Screenshot / Preview: ![Portfolio Preview](./card.jpg)


---

## 🛠 Tech Stack

- **Framework:** React (JavaScript, JSX)
- **Styling:** Custom CSS, Bootstrap
- **Icons:** Font Awesome / React Font Awesome
- **Build Tooling:** Create React App (or similar React setup)

- `Education.jsx` – education cards with glowing icons and timeline-like layout.  
- `Project.jsx` – renders projects from a `projectData` array in a custom timeline.  
- `ProjectCard.jsx` – reusable card for individual projects (view / code links).  
- `style.css` – global styles, card design, animations, and background effects.
